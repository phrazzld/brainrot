# Retired Vercel scripts

These files are historical migration and maintenance references from before
Brainrot completed its DigitalOcean cutover in 2026. They are deliberately
outside every workspace, workflow, build, and operator command.

Do not run them against production. Their Vercel dependencies and credentials
were removed after the Vercel project and Blob store were retired. Current
content publishing is `pnpm sync:spaces`; current asset reads use DigitalOcean
Spaces.
