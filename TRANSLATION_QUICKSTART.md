# translation quickstart guide

## core rules (non-negotiable)

### formatting
- **all lowercase** (no capitals except rare emphasis)
- **plain markdown prose** - readable paragraphing, no fancy typography
- **chapter length parity** - target within ~10-15% of source

### density requirements
- **3-5+ brainrot terms per sentence MINIMUM**
- **1,600+ core term occurrences per book**
- **maximize chaos while preserving plot**

### example transformation
```
original: "In my younger and more vulnerable years..."
brainrot: "back when i was a lil sus beta and way more vulnerable to getting absolutely ratio'd by life"
```

## essential vocabulary (use constantly)

### top priority terms (proven high-impact)
- **fr** - for real
- **lowkey** - subtle admission
- **no cap** - no lie
- **it's giving [x] energy** - describing vibes
- **literally** - emphasis
- **absolutely** - intensity amplifier
- **unhinged** - chaotic behavior
- **aesthetic** - visual/cultural vibes
- **npc** - background character energy
- **chronically online** - internet-poisoned perspective

### core brainrot terms (use liberally)
- skibidi, gyatt, rizz, sigma, alpha, beta
- bussin, mid, cringe, based, ratio
- simp, stan, ship, main character
- touch grass, no thoughts head empty
- rent-free, living for this, obsessed

## character voice mapping

### assign each major character 3-5 signature terms

examples from successful gatsby translation:
- **narrator**: "yo", "bestie", "fr", "lowkey" 
- **mysterious wealthy**: "sigma bro" terminology
- **manipulative socialite**: valley girl - "literally", "iconic", "obsessed"
- **toxic male**: alpha terminology - "territory", "dominance"

## problematic content handling

### NEVER reproduce historical slurs

use systematic replacements:
- n-word → "the hard-r yikesword" 
- ethnic slurs → "boomer slur for [group]"
- ableist/homophobic → "yikesword about [category]"

maintain consistency - same replacement every time

## quality checklist

before submitting any translation:
- [ ] all lowercase formatting?
- [ ] 3-5+ brainrot terms per sentence?
- [ ] character voices consistent?
- [ ] plot 100% preserved?
- [ ] no actual slurs used?
- [ ] maximalist gremlin mode achieved?

## remember

you're creating a **chaotic, meme-dense word salad** that somehow still tells the exact same story. when in doubt, add more brainrot.
